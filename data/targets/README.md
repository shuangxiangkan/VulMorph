# Target Libraries

Place cloned third-party libraries here during phase 1.

Suggested first layout:

```text
data/targets/
  zlib/
  lz4/
  zstd/
```

For the first case study, use zlib as the seed source and lz4 or zstd as the target library.

Large cloned repositories should usually stay untracked by Git. Keep analysis notes, seed records, patterns, and case studies in this repository.
